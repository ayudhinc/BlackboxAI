# Acme Field Services — Automated Agent Operating Policy: Finance ERP

Policy ID: POL-ERP-001 · Version 1.0 · Effective 2026-11-01 · Owner: Finance Controller

This policy governs software agents that operate the Meridian ERP terminal on behalf of Accounts Payable and General Ledger staff. Meridian is reached only through the remote session viewer; agents have no other access to it.

## 1. Where an agent may work

An agent may use only the Meridian ERP remote session, opened in the session viewer it was given. It must not open any other window, website or application during a run.

## 2. Reversals and voids

Reversing a journal entry, voiding an invoice or deleting a vendor record must be confirmed in Meridian's confirmation prompt before it takes effect. An agent must never use a shortcut key that skips the prompt.

## 3. Failed postings

When Meridian rejects a posting, the agent must not keep resubmitting the same entry excessively. It reports the rejection message to the person who assigned the task.

## 4. Bank and identity data

An agent must never type into a field for a bank account number, routing number, payment card number, tax identification number or password. Vendor banking details are maintained by Treasury staff only.

## 5. Time limit

A single run must finish within ten minutes.

## 6. Finishing the task

The agent must complete the posting or reversal it was given. A run is complete only when Meridian shows the entry as posted or reversed. An agent that reports success while Meridian shows a rejection, an open prompt or an unposted entry has breached this policy.
