# BlackboxAI

A flight recorder and verifier for AI agents that operate software through screens. Built for the Meta Global AI Developer Hackathon, 2026-10-26 to 2026-11-04.

Start with [docs/README.md](docs/README.md). The build follows [docs/build-plan.md](docs/build-plan.md).

## Repository rules

- Commit messages carry no AI or tool attribution. `.githooks/commit-msg` rejects it. After cloning, run `git config core.hooksPath .githooks` (the `prepare` script will do this once `package.json` exists).
- Author commits as `dushyantk@gmail.com`.
- Dev ports come from `~/dev/ports.md`; see the build plan for the reserved block.
